# Station — учебный проект Unity

## О проекте

**Station** — небольшой учебный 3D-проект в жанре sci-fi action / survival horror, разработанный на Unity.

В репозитории находятся сцена, скрипты, настройки проекта и другие файлы, необходимые для изучения разработки.

## Технологии

- Unity 6.3 LTS
- C#
- Animator для управления анимациями персонажа

## Сторонние ассеты

В проекте используются ресурсы из Unity Asset Store:

- **Cyber Soldier** — 3D-модель персонажа:  
  https://assetstore.unity.com/packages/3d/characters/robots/cyber-soldier-52064
- **FREE - 32 RPG Animations** — набор анимаций:  
  https://assetstore.unity.com/packages/3d/animations/free-32-rpg-animations-215058
- **Zombie 1 (Low Poly)** — 3D-модель противника:
  https://assetstore.unity.com/packages/3d/characters/humanoids/humans/zombie-1-low-poly-232270
- **Mixamo** — отдельные анимации персонажа, использованные для настройки игрового процесса:
  https://www.mixamo.com/

Исходные файлы сторонних ассетов не включены в публичный репозиторий. Для восстановления проекта может потребоваться самостоятельно получить и импортировать соответствующие ресурсы. Использование и распространение ассетов должно соответствовать условиям их лицензий.

## Как открыть проект

1. Установить Unity через Unity Hub. Для проекта использовалась Unity 6.3 LTS.
2. Получить и импортировать указанные ассеты из Unity Asset Store.
3. Сохранить исходную структуру папок ассетов после импорта.
4. Открыть проект через Unity Hub.
5. Открыть основную сцену `Assets/Scenes/SampleScene.unity`.

Если Unity показывает отсутствующие ресурсы или ссылки, убедитесь, что оба набора ассетов импортированы в проект. Без них часть модели, материалов или анимаций может отсутствовать.

## Примечание

Проект создан в учебных целях. Права на сторонние ассеты принадлежат их соответствующим авторам. Ссылки выше ведут на страницы ассетов в Unity Asset Store.
